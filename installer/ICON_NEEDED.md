# Иконка для инсталлера

Для завершения UI необходимо создать иконку приложения.

## Где разместить:
`installer/res/icon.ico`

## Требования к иконке:
- Формат: .ICO (Windows Icon)
- Размеры: Рекомендуется включить несколько размеров в один файл:
  - 16x16
  - 32x32
  - 48x48
  - 256x256
- Стиль: Простая, узнаваемая иконка, связанная с экспортом данных

## Как создать:
1. **Онлайн инструменты:**
   - https://www.favicon-generator.org/
   - https://convertio.co/ru/png-ico/

2. **Программы:**
   - GIMP (бесплатно)
   - Adobe Illustrator / Photoshop
   - Inkscape (бесплатно)

3. **Простой вариант:** Использовать стандартную иконку Windows для установщиков

## После создания:
1. Поместить `icon.ico` в `installer/res/`
2. Пересобрать проект: `cargo build --release --package data-exporter-installer`
3. Иконка автоматически встроится в .exe через build.rs

## Примеры идей для иконки:
- Папка с стрелкой (символ экспорта)
- База данных с шестеренкой
- Документ с кружочком/галочкой
- Комбинация DBF + стрелка вправо
