# Implementation Plan: Data Exporter Windows Service

**Branch**: `001-data-exporter-service` | **Date**: 2026-01-24 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-data-exporter-service/spec.md`

## Summary

Windows background service for automated DBF file export to CSV format with server upload. The service runs on a cron schedule, converts legacy DBF files (with multi-encoding support), compresses to GZIP, and uploads via HTTP multipart. Handles locked files via VSS, implements retry logic for network failures, and provides comprehensive error reporting.

**TDD Approach**: All implementation follows Test-Driven Development - tests written first, approved, verified failing, then implementation to pass tests.

## Technical Context

**Language/Version**: Rust 1.82.0 (stable, as per `rust-version` in Cargo.toml)
**Primary Dependencies**:
- `windows-service` 0.7 - Windows SCM integration
- `tokio-cron-scheduler` 0.13 - Async cron scheduling
- `dbase` 0.5 + `yore` - DBF parsing with encoding support
- `reqwest` 0.12 - HTTP client with multipart
- `flate2` 1.x - GZIP compression
- `globset` 0.4 - File pattern matching
- `rawcopy-rs` 0.1 - VSS shadow copy

**Storage**: File-based (DBF source, temp CSV, GZIP output)
**Testing**: `cargo test` + `wiremock` for HTTP mocking + `tempfile` for fixtures
**Target Platform**: Windows 10+ / Windows Server 2016+
**Project Type**: Workspace (common library + service binary + configurator)
**Performance Goals**: Process files up to 10MB in memory, larger via temp files
**Constraints**: 5-minute upload timeout, 3 retries with exponential backoff (1s, 2s, 4s)
**Scale/Scope**: Single service instance, configurable file patterns, daily log rotation

## Dependencies & Risk Areas

| Component | Risk | Mitigation |
|-----------|------|------------|
| Windows Service | Admin privileges for testing | Use `#[ignore]`, separate CI job |
| VSS | Not available on all systems | Feature flag, graceful fallback |
| Encoding | Various DBF header formats | Test fixtures, fallback encoding |
| Network | Transient failures | Retry with backoff, local logging fallback |
